# ГЛОССАРИЙ
## Система управления задачами (TaskFlow)

---

## А

**API (Application Programming Interface)**
Интерфейс программирования приложений. Набор правил и протоколов для взаимодействия между приложениями.

**Аутентификация**
Процесс проверки личности пользователя (вход в систему с email и пароль).

**Авторизация**
Процесс проверки прав доступа пользователя к ресурсам системы.

**Аватар**
Изображение профиля пользователя.

---

## Б

**Backend**
Серверная часть приложения, которая обрабатывает логику и работает с БД.

**Bcrypt**
Алгоритм хеширования паролей, обеспечивающий безопасное хранение паролей.

**БД (База данных)**
Структурированное хранилище данных.

**Браузер**
Программа для просмотра веб-сайтов (Chrome, Firefox, Safari, Edge).

---

## В

**Валидация**
Проверка корректности входных данных.

**Версионирование**
Управление различными версиями кода (Git).

**Веб-приложение**
Приложение, работающее в браузере через интернет.

**Вложенность**
Иерархическая структура данных (например, подзадачи в задачах).

---

## Г

**Гост (Guest)**
Неавторизованный пользователь, имеющий ограниченный доступ.

**Графики и диаграммы**
Визуальное представление данных (графики, круговые диаграммы, столбчатые диаграммы).

---

## Д

**DevOps**
Специалист, занимающийся развертыванием и управлением инфраструктурой.

**Docker**
Технология контейнеризации приложений.

**Документация**
Описание функциональности и использования системы.

**Дополнительные функции**
Функции, которые не являются критическими, но улучшают пользовательский опыт.

---

## Е

**Email**
Электронная почта.

**Экспорт**
Сохранение данных в другом формате (PDF, CSV).

---

## Ж

**Жизненный цикл задачи**
Этапы развития задачи: создание → выполнение → завершение.

---

## З

**Задача (Task)**
Единица работы, которую нужно выполнить.

**Заголовок**
Название задачи или проекта.

**Запрос (Request)**
Отправка данных на сервер.

**Защита от атак**
Механизмы безопасности для предотвращения несанкционированного доступа.

---

## И

**Индекс**
Структура БД для ускорения поиска данных.

**Интеграция**
Объединение различных систем для совместной работы.

**Интерфейс**
Способ взаимодействия пользователя с приложением.

**Итерация**
Цикл разработки с улучшениями на основе отзывов.

---

## К

**Кеширование**
Сохранение часто используемых данных для быстрого доступа.

**Клиент (Client)**
Часть приложения, работающая на компьютере пользователя (Frontend).

**Код**
Текст программы на языке программирования.

**Комментарий**
Текстовое сообщение, добавленное к задаче.

**Компонент**
Переиспользуемая часть интерфейса.

**Контроль доступа**
Система управления правами пользователей.

**Конфигурация**
Настройки приложения.

**Кроссплатформенность**
Возможность работать на разных платформах (Windows, macOS, Linux).

---

## Л

**Лицензия**
Правовой документ, определяющий условия использования ПО.

**Локализация**
Адаптация приложения для разных языков и регионов.

---

## М

**Маршрутизация**
Определение пути запроса в приложении.

**Масштабируемость**
Способность системы расти и обрабатывать больше данных.

**Мобильное приложение**
Приложение для смартфонов и планшетов.

**Модель**
Структура данных в БД.

**Модульность**
Разделение кода на независимые модули.

**Мониторинг**
Отслеживание состояния и производительности системы.

---

## Н

**Нефункциональные требования (NFR)**
Требования к производительности, безопасности, масштабируемости и т.д.

**Нотификация**
Уведомление пользователю.

---

## О

**Оптимизация**
Улучшение производительности и эффективности.

**Ответ (Response)**
Данные, отправленные сервером в ответ на запрос.

**Отчет**
Документ с анализом данных.

---

## П

**Пагинация**
Разделение большого списка на страницы.

**Параметр**
Переменная, передаваемая в функцию или запрос.

**Парольный хеш**
Зашифрованное представление пароля.

**Пользователь**
Человек, использующий приложение.

**Приватный проект**
Проект, видимый только его членам.

**Приоритет**
Уровень важности задачи (высокий, средний, низкий).

**Проект**
Группа связанных задач.

**Производительность**
Скорость работы приложения.

**Публичный проект**
Проект, видимый всем пользователям.

---

## Р

**Рабочий процесс (Workflow)**
Последовательность действий для выполнения задачи.

**Разработчик**
Специалист, пишущий код.

**Резервная копия**
Копия данных для восстановления при сбое.

**Репозиторий**
Хранилище кода (Git).

**REST API**
Архитектурный стиль для создания веб-сервисов.

**Роль**
Набор прав доступа пользователя (admin, member, guest).

---

## С

**Сессия**
Период активности пользователя в приложении.

**Сервер**
Компьютер, на котором работает Backend приложения.

**Сертификат SSL**
Документ для защиты соединения (HTTPS).

**Синхронизация**
Обновление данных между различными частями системы.

**Система управления версиями**
Инструмент для отслеживания изменений кода (Git).

**Скрипт**
Небольшая программа для автоматизации задач.

**Сортировка**
Упорядочивание данных по определенному критерию.

**Спецификация**
Подробное описание требований и функциональности.

**Срок выполнения (Due Date)**
Дата, к которой должна быть выполнена задача.

**Статус**
Текущее состояние задачи (todo, in_progress, done).

**Статистика**
Анализ данных и метрик.

---

## Т

**Таблица**
Структура БД для хранения данных.

**Тег**
Метка для категоризации задач.

**Тестирование**
Проверка функциональности приложения.

**Техническое задание (ТЗ)**
Документ с описанием требований к проекту.

**Токен**
Уникальный идентификатор для аутентификации.

**Транзакция**
Группа операций БД, выполняемых вместе.

**Трудозатраты**
Количество времени, необходимое для выполнения задачи.

---

## У

**Удаленная работа**
Работа из дома или другого места, не в офисе.

**Упоминание (@mention)**
Ссылка на пользователя в комментарии.

**Управление проектами**
Организация и контроль выполнения проектов.

**Управление задачами**
Организация и контроль выполнения задач.

**Уведомление**
Сообщение для пользователя о событии в системе.

---

## Ф

**Фильтрация**
Выбор данных по определенным критериям.

**Фреймворк**
Набор инструментов и библиотек для разработки.

**Функциональные требования (FR)**
Описание того, что система должна делать.

---

## Х

**Хеширование**
Преобразование данных в фиксированную строку (для паролей).

**Хостинг**
Сервис для размещения приложения в интернете.

---

## Ц

**Целевая аудитория**
Группа людей, для которых предназначено приложение.

**Цель проекта**
Что нужно достичь в результате разработки.

---

## Ч

**Чек-лист**
Список задач для отслеживания прогресса.

**Часовой пояс**
Географическая зона с определенным временем.

---

## Ш

**Шифрование**
Преобразование данных в неразборчивый вид для защиты.

---

## Э

**Экспорт**
Сохранение данных в другом формате.

**Экран**
Страница приложения.

**Элемент интерфейса**
Кнопка, поле ввода, список и т.д.

---

## Ю

**Юзабилити**
Удобство использования приложения.

---

## Я

**Язык программирования**
Система правил для написания кода (JavaScript, Python, Java).

**Язык разметки**
Язык для описания структуры документов (HTML, XML).

**Язык стилей**
Язык для описания внешнего вида (CSS).

## ТЕХНОЛОГИИ И ИНСТРУМЕНТЫ

### Frontend
- **React** — библиотека для создания интерфейсов
- **Vite** — сборщик проекта
- **Tailwind CSS** — фреймворк для стилизации
- **Redux** — управление состоянием
- **Axios** — HTTP клиент
- **React Router** — маршрутизация

### Backend
- **Node.js** — среда выполнения JavaScript
- **Express.js** — веб-фреймворк
- **PostgreSQL** — база данных
- **Sequelize** — ORM
- **Passport.js** — аутентификация
- **Socket.io** — real-time коммуникация

### DevOps
- **Docker** — контейнеризация
- **GitHub Actions** — CI/CD
- **Heroku** — облачный хостинг
