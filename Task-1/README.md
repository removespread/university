## 🎯 Краткое описание проекта

**TaskFlow** — это веб-приложение для управления личными и командными задачами.

### Основные функции:
- ✅ Управление задачами (создание, редактирование, удаление)
- ✅ Организация по проектам, категориям, приоритетам
- ✅ Совместная работа (приглашение пользователей, назначение задач)
- ✅ Комментарии и упоминания
- ✅ Уведомления и напоминания
- ✅ Статистика и отчеты
- ✅ Поддержка мобильных устройств

### Целевая аудитория:
- Фрилансеры и удаленные работники
- Студенты и учащиеся
- Менеджеры проектов
- Малые и средние компании

## 🛠️ Технический стек

### Frontend
```
React 18.x
├── React Router v6 (маршрутизация)
├── Redux Toolkit (управление состоянием)
├── Tailwind CSS (стилизация)
├── Axios (HTTP клиент)
├── React Query (управление данными)
├── React Hook Form (формы)
├── Recharts (графики)
└── Vite (сборщик)
```

### Backend
```
Node.js + Express.js
├── TypeScript (типизация)
├── Sequelize/TypeORM (ORM)
├── Passport.js (аутентификация)
├── JWT (токены)
├── Socket.io (real-time)
├── Nodemailer (email)
└── PostgreSQL (БД)
```

### DevOps
```
Docker & Docker Compose
GitHub Actions (CI/CD)
Heroku/Railway/Render (хостинг)
```

## 📋 Требования к системе

### Функциональные требования (FR):
- **FR-1:** Аутентификация и авторизация
- **FR-2:** Управление профилем
- **FR-3:** Управление проектами
- **FR-4:** Управление задачами
- **FR-5:** Комментарии и упоминания
- **FR-6:** Уведомления
- **FR-7:** Отчеты и статистика

### Нефункциональные требования (NFR):
- **NFR-1:** Производительность (загрузка ≤ 2 сек, API ≤ 500 мс)
- **NFR-2:** Безопасность (HTTPS, защита от атак, GDPR)
- **NFR-3:** Масштабируемость (10,000+ активных пользователей)
- **NFR-4:** Доступность (uptime ≥ 99.5%)
- **NFR-5:** Адаптивность (все браузеры, мобильные устройства)

---

## 🔐 Безопасность

### Реализованные меры:
- ✅ HTTPS для всех данных
- ✅ Хеширование паролей (bcrypt)
- ✅ JWT токены для аутентификации
- ✅ Защита от CSRF, SQL инъекций, XSS атак
- ✅ Rate limiting для предотвращения brute-force
- ✅ Логирование и мониторинг
- ✅ Соответствие GDPR
