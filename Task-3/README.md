# Task-3 — Тестирование TaskFlow

Комплексный набор автоматизированных тестов для backend приложения
**TaskFlow** (`Task-2/backend`). Включает модульные (unit) и интеграционные
(integration) тесты, измерение покрытия кода и документацию по тестированию.

> Тестируемый код находится в соседнем проекте [`Task-2/backend`](../Task-2/backend).
> Тесты вынесены в отдельный проект `Task-3`, чтобы не смешивать тестовую
> инфраструктуру с продуктовым кодом.

---

## 🛠 Технологии тестирования

| Инструмент    | Назначение                                             |
| ------------- | ------------------------------------------------------ |
| **Jest**      | Тест-раннер, ассершены, моки, измерение покрытия (V8)  |
| **Supertest** | HTTP-запросы к Express-приложению (интеграционные тесты) |
| **SQLite (in-memory)** | Изолированная БД для тестов без внешних зависимостей |

Обоснование выбора — Jest уже используется в `Task-2`, что обеспечивает
единообразие инструментов. Supertest — стандарт де-факто для тестирования
Express-API.

## 🚀 Установка и запуск

### Предварительные требования

- Node.js ≥ 18
- Установленные зависимости backend (`Task-2/backend/node_modules`) — они нужны
  тестируемому приложению (express, sequelize, sqlite3, jsonwebtoken и т.д.):

```bash
cd ../Task-2/backend && npm install
```

### Установка зависимостей тестов

```bash
cd Task-3
npm install
```

### Запуск

```bash
npm test                 # все тесты
npm run test:unit        # только модульные
npm run test:integration # только интеграционные
npm run test:coverage    # все тесты + отчёт о покрытии
npm run test:watch       # режим наблюдения (watch)
```

Отчёт о покрытии в формате HTML открывается файлом `coverage/lcov-report/index.html`.

## 📊 Покрытие кода

Целевой порог — **не менее 70%** по всем метрикам (задан в `jest.config.js`
через `coverageThreshold`). Фактически достигнуто **≈94% строк**.
