## Итого

- **Позитивных сценариев:** проверяют корректную работу при валидных данных.
- **Негативных сценариев:** проверяют обработку ошибок и некорректного ввода.
- **Граничных условий:** пустые/отсутствующие значения, сброс полей, крайние состояния.
